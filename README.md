Introducción

En esta práctica se implementan dos tipos de pilas en el lenguaje Java: una pila estática y una pila dinámica. Ambas estructuras permiten almacenar y organizar datos siguiendo el principio LIFO (Last In, First Out), que significa que el último elemento en entrar es el primero en salir.

Objetivo

Comprender el funcionamiento de las pilas estáticas y dinámicas, así como identificar sus diferencias mediante la programación en Java.

Desarrollo

Pila estática

La pila estática utiliza un arreglo para almacenar los elementos. Su capacidad se establece previamente y no puede crecer automáticamente durante la ejecución.

Pila dinámica

La pila dinámica utiliza nodos enlazados para almacenar los elementos. Su tamaño puede aumentar o disminuir según las operaciones realizadas y la memoria disponible.

Principio LIFO

El principio LIFO establece que el último elemento agregado a la pila será el primero en retirarse.

Operaciones principales

- Push: agrega un elemento a la pila.
- Pop: elimina el elemento que se encuentra en la parte superior.
- Peek: consulta el elemento superior sin eliminarlo.
- isEmpty: verifica si la pila está vacía.

Conclusión

La práctica permite comprender cómo funcionan las pilas y cómo se pueden implementar mediante arreglos y nodos enlazados. La pila estática tiene una capacidad definida, mientras que la dinámica ofrece mayor flexibilidad en el manejo de los elementos. Ambas son útiles para resolver diferentes problemas de programación.
